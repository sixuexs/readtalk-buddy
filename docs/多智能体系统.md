# 阅谈智伴多智能体系统

## 架构概览

```
┌─────────────────────────────────────────────────────────────────┐
│                        AgentRegistry（弱中心）                    │
│  职责：注册发现 · 共享配置 · 事件总线 · 不做路由和不做编排         │
└──────────────────────────┬──────────────────────────────────────┘
                           │
        ┌──────────────────┼──────────────────┐
        │                  │                  │
   ┌────┴────┐      ┌─────┴─────┐     ┌─────┴─────┐
   │ 事件驱动  │      │ 直接调用   │     │ 共享状态   │
   │ Spring   │      │ Agent     │     │ MongoDB   │
   │ Event    │      │ .call()   │     │           │
   └────┬────┘      └─────┬─────┘     └─────┬─────┘
        │                  │                  │
┌───────┴──────────────────┴──────────────────┴───────────────────┐
│                        5 个特化 Agent                            │
├────────────┬────────────┬────────────┬────────────┬─────────────┤
│ 情境模拟    │ 用户画像    │ 破冰分析    │ 关系运维    │ 沟通辅助     │
│ Simulation │ Profile    │ IceBreak   │ Relation   │ CommAssist  │
└────────────┴────────────┴────────────┴────────────┴─────────────┘
```

### 为什么弱化中心 Agent

传统中心 Agent 做一切请求路由 → 每次调用多一跳延迟，成为单点瓶颈。

取而代之：
- 每个场景直接调用对应的特化 Agent
- Agent 间通过 **Spring Event** 松耦合通信
- 共享数据通过 **MongoDB** 读写

### 技术栈

| 层 | 选型 | 版本 |
|---|---|---|
| Agent 框架 | Spring AI Alibaba Graph | 1.1.2.3 |
| Agent 类型 | ReactAgent（ReAct 模式） | — |
| LLM | DeepSeek | deepseek-v4-flash |

## Agent 公共接口

```java
public interface Agent {
    String name();           // 唯一标识
    String description();    // 能力描述
    ReactAgent reactAgent(); // 底层 ReactAgent 实例
}
```

所有 Agent 实现此接口，通过 `@Component` 注解自动注册到 `AgentRegistry`。上层代码面向接口编程，不依赖具体实现。

## 5 个特化 Agent

### 1. 情境模拟 Agent（simulation-agent）

> 负责情景对话生成、角色扮演、对话结束后的多维度评分

| Tool | 参数 | 说明 |
|---|---|---|
| `startSimulation` | theme, personality | 创建新会话，返回 AI 开场白 |
| `sendMessage` | sessionId, message | 发送消息并获取 AI 角色回复 |
| `scoreConversation` | sessionId | 对完整对话进行 AI 多维度评分 |

**评分维度**：表达力、亲和力、逻辑性（各 0-100），附带评语、优点标签、改进建议。

**数据**：MongoDB `conversation` 集合，消息内嵌在会话文档中。

**事件**：评分完成后发布 `ScoringCompletedEvent`，用户画像 Agent 自动监听更新。

---

### 2. 用户画像 Agent（user-profile-agent）

> 聚合所有历史评分数据，生成能力评估与个性化提升计划

| Tool | 参数 | 说明 |
|---|---|---|
| `getProfile` | — | 获取用户画像（各维度均分、趋势、优劣势） |
| `assessAbility` | — | 汇总所有已评分会话，AI 生成评估 + 提升计划 |

**输出**：综合评分、表达力/亲和力/逻辑性均分、趋势数据、AI 评语、优势标签、短板标签、每周目标。

**数据**：MongoDB `user_profile` 集合。

**事件监听**：`@EventListener` 监听 `ScoringCompletedEvent`，评分后自动更新画像，无需手动触发。

---

### 3. 破冰分析 Agent（ice-break-agent）

> 扫描名片后分析双方信息，生成破冰策略

| Tool | 参数 | 说明 |
|---|---|---|
| `analyzeCard` | myInterests, myLabels, otherInterests, otherLabels, otherPersonality, context | 分析名片 + 当前情境 → 破冰建议 |

**输出**：建议话题列表、破冰策略、注意事项、共同点挖掘。同时自动创建联系人记录。

**数据**：MongoDB `contacts` 集合（联系人名片信息）。

**触发**：用户点击「扫码连接」→ 调用 Agent。

---

### 4. 关系运维 Agent（relation-agent）

> 亲密度管理、维护提醒、疏远预警、挽回方案

| Tool | 参数 | 说明 |
|---|---|---|
| `listContacts` | — | 获取所有联系人列表 |
| `calcIntimacy` | contactId | 计算亲密度（互动频率 + 时间衰减） |
| `checkMaintenance` | — | 检查生日提醒、未联系提醒、疏远预警 |
| `detectDrift` | contactId | 检测单联系人疏远程度 |
| `generateRecoverPlan` | contactId, chooseRecover | AI 生成挽回方案；不挽救则抑制预警 30 天 |

**亲密度算法**：基础分 + 互动频率加成（每次 +2，上限 +20） - 时间衰减（每周 -1，上限 -15）。

**预警规则**：亲密度 < 40 分 或 超 30 天未联系 → 触发预警。

**数据**：MongoDB `contacts` 集合。

---

### 5. 沟通辅助 Agent（comm-assist-agent）

> 实时分析用户语言表达，给出沟通建议

| Tool | 参数 | 说明 |
|---|---|---|
| `analyzeSpeech` | text, context, sessionId | 分析输入→态度识别+情绪感知+改进建议 |
| `scorePerformance` | sessionId | 沟通结束后综合评分 |

**分析维度**：态度（积极/消极/中性/攻击性/回避）、情绪、清晰度、改进版表达、沟通小贴士。

**评分维度**：综合分、态度分、清晰度分、共情分 + 亮点 + 改进点。

**数据**：暂用内存存储（后续可迁移至 MongoDB）。

**触发**：用户点击「沟通辅助」→ 语音输入 → 实时分析。

## Agent 间通信

### 事件驱动（松耦合）

```
SimulationService.scoreConversation()
  → 发布 ScoringCompletedEvent
    → UserProfileListener 监听到
      → 自动调用 UserProfileTools.assessAbility()
        → 更新 user_profile 集合
```

```
IceBreakTools.analyzeCard()
  → 创建联系人
  → 发布 ContactAdded 事件（预留，RelationAgent 可监听）
```

### 共享 MongoDB

各 Agent 通过读写同一数据库共享上下文：
- `conversation` → 情境模拟读写、用户画像读取
- `user_profile` → 用户画像写入、破冰分析读取
- `contacts` → 破冰分析写入、关系运维读写

### 直接调用

上层代码通过 `AgentRegistry.get("xxx")` 获取 Agent，调用 `agent.reactAgent().call(input)` 或直接访问 `@Tool`方法。

## 如何新增 Agent

1. 创建 `XxxTools.java` — `@Component` + `@Tool` 方法
2. 创建 `XxxAgent.java` — `@Component` + `implements Agent`
3. 无需其他配置 — `AgentRegistry` 自动发现并注册
4. 如需数据 → 创建 Document + Repository
5. 如需事件 → 发布/监听 `AgentEvent`
