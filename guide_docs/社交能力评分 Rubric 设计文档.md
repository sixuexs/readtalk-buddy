# 阅谈智伴 · 社交能力评分 Rubric 设计文档（B 终态）

> 版本：B 终态。配套文档：《评价体系数据结构设计文档》（下称 C 文档）。
> 适用范围：定义"AI 如何对 5 维社交能力打分"，是 AI 评分 prompt、前端雷达图/折线图、亲密度深度/质量分量、差异觉察机制的**共同输入基线**。
> 使用方：① AI 模块负责人（据此写 `scoreConversation` 各维 prompt）；② 前端（据此渲染与做差异觉察文案）；③ 封测校准（据此核对评分方差与标尺）。
> 不在范围：overall 综合分计算（见 C 文档，第一版等权 = ROUND(AVG 五维)）、亲密度公式（见 C 文档 §7）、前端交互。

## 0. 对齐声明

### 0.1 与申报书维度的映射（答辩口径桥）⚠️
申报书"会后评估"原文为四维：表达清晰度、逻辑性、互动质量、共情能力。本设计细化为五维，映射如下，**答辩/论文须按此口径说明，避免与申报书字面对不齐**：

| 申报书原文 | 本设计维度（短名） | 关系 |
|---|---|---|
| 表达清晰度 | `clarity` | 直接对应 |
| 逻辑性 | `logicality` | 直接对应 |
| 共情能力 | `empathy_listening` | 扩展：补"倾听"子能力 |
| 互动质量 | `interactivity` | 细化：聚焦"推动/维持/邀请"动作 |
| （申报书未单列） | `relaxation` | **本项目特色新增**，对应申报书立项动机"线下紧张/回避"痛点 |

### 0.2 命名规则（引用 C 文档 §0.2，禁止起别名）
5 维短名 = `clarity` / `logicality` / `empathy_listening` / `interactivity` / `relaxation`。
- DB 列 = `score_` + 短名；JSON 键（`self_relative`、rubric 产出、divergence 现算）= 短名；Java/TS 字段 = camelCase（`empathyListening` 等）。
- 本文档所有 prompt 片段、指标、锚定均按短名对齐。

### 0.3 与数据层的钩子对齐
- `empathy_listening` 的"延展率"子项对应 C 文档 §5 `messages[].annotation` 中的 `responds_to_seq`；
- `annotation` 在 C 文档为 string 存 JSON，本 rubric 仅**语义借用**其字段，不硬绑枚举值（词表标准化见挂记④）。

## 1. 设计原则（统摄五维）

1. **正交性**：一个语言特征只计入一维。维度间易混特征的归属见 §2 撞车仲裁表，AI 提取特征时按仲裁规则判，否则相邻维高度相关、雷达图失去区分度。
2. **标尺一致（real / simulation 同标尺）**：每维四档锚定两源共用；prompt 禁止出现"语音/线下/面对面"等仅适用 real 的模态词。各维按自身特征选取消偏差手段（密度+阈值 / 语义为主标点弱辅助 / 禁臆测语音），见各维"标尺与置信度"。
3. **防刷分哲学**：每维都设"伪信号不得正向分"的护栏（关联词套壳、空洞附和、纯沉默、退缩词缺失但无输出等），使分数对应真实能力而非话术。
4. **文本可测性边界**：规则可算的指标给计算口径；语义指标交模型判断并承认方差；不可由文本测准的（relaxation 的副语言信号）显式降级为"近似推断"，不伪装精确。
5. **存事实/算派生/评整篇**：rubric 产出的是"整篇级单维分"，落 C 文档 evaluation_record / conversations.Evaluation；逐句特征（关键词/情绪/回应指向）是 annotation 层，不在本 rubric 直接打分。

## 2. 撞车仲裁表（横切规则）

> 原则：下表只列"会被两维争抢"的特征；独占特征在各维 rubric 内写。AI prompt 必须按"仲裁规则"做特征归属。

| # | 易混语言特征 | 争抢维度 | 仲裁规则（归谁 / 判据） |
|---|---|---|---|
| 1 | 停顿填充词：那个 / 就是说 / 嗯 / 啊 / 呃 | clarity ↔ relaxation | **归 clarity**。判据：打断的是语言组织，非自我价值。relaxation 不收填充词。 |
| 2 | 自我贬低/不确定/退缩词：可能我不对 / 随便说说 / 我说不好 / 我也不确定 | relaxation ↔ clarity | **归 relaxation**。判据：对自我观点的不自信，非词不达意。clarity 不收（clarity prompt 已显式排除）。 |
| 3 | 道歉/退让词：不好意思 / 抱歉 / 打扰一下 | relaxation ↔ empathy | **看后接内容**：后接退让/收回观点→归 relaxation；后接肯定对方→肯定语义归 empathy，**道歉词本身只可能是 relaxation 信号，绝不作 empathy 正向**。 |
| 4 | 句长 / 句子完整 / 半截句 | clarity ↔ logicality | 句法层面（单句是否说完整、自我推翻重说）归 clarity；结构层面（句间是否有条理/支撑）归 logicality。 |
| 5 | "然后" | clarity ↔ logicality | 连续/堆叠"然后…然后…"=口头禅填充→归 clarity 扣分；**单次连接两个有先后/因果分句=逻辑连接词→归 logicality**（由 logicality 关联词指标显式接收，见 §3.2 边界）。 |
| 6 | 提问句 / 反问句 | interactivity ↔ logicality ↔ empathy | 见各维边界：共情性追问→empathy；征询/推动/破冰提问与征询性反问→interactivity；修辞性反问→logicality。 |

**填充词计算口径**：clarity 的填充词按**密度**（每百字填充词数）算，不按绝对次数；容忍阈值初值 **<3/百字不扣**（常量待校准）。理由：中文口语/语音复盘天然带填充，按绝对次数扣会使 real 分系统性低于 sim 文字，破坏标尺一致。

## 3. 五维 Rubric

### 3.1 clarity（表达清晰度）

**定义**：能否准确、流畅地输出观点与读书感悟，不词不达意、不冗赘。**只评"说清楚"，不评对错/条理**（归 logicality）。

**可测指标**：

| 指标 | 计算口径 | 方向 |
|---|---|---|
| 填充词密度 | 每百字填充词数（§2#1 词表），<3 不扣 | 越高越差 |
| 句法完整率 | 完整句/总句；半截句、自我推翻重说计不完整 | 越低越差 |
| 冗余率 | 同一意思重复表述的句对占比 | 越高越差 |
| 用词准确度 | 词不达意/反复用同一模糊指代（"那个东西""反正"）的频次 | 越高越差 |

> "然后"堆叠计入填充词密度（§2#5）；单次连接用"然后"不计入。

**四档锚定**：

| 档位 | 区间 | 含义 | 沙龙场景示例 |
|---|---|---|---|
| 差 | 0–39 | 填充密集、大量半截句或词不达意 | "就是…那个…我觉得吧，嗯，怎么说呢，就是那书里，反正就是…我说不太清。" |
| 及格 | 40–69 | 能表达观点，但有明显冗余/填充/偶有词不达意 | "我觉得主角挺矛盾的，就是…他一方面想逃，然后另一方面又…嗯，反正就是没面对吧。" |
| 良好 | 70–89 | 观点清晰、表达流畅，偶有 1–2 处填充 | "我认为主角的逃避是一种自我保护，虽然他最终没能面对，但这个选择本身是合理的。" |
| 优秀 | 90–100 | 精准简洁、无冗余、用词准确 | "主角的逃避并非懦弱，而是创伤下的自我保护机制——这正是本书最打动我的地方。" |

**边界**：单句内问题（半截句、口误级自我修正）归本维；跨句/观点级问题归 logicality。本维不收自我贬低词（§2#2）、不收道歉词（§2#3）。

**标尺与置信度**：全部指标文本可测、与模态无关；real/sim 同锚定同填充词阈值；prompt 禁模态词。

**prompt 片段**：
```
【clarity 表达清晰度 0-100】
只评"是否说清楚"，不评对错与条理（条理归 logicality）。
特征归属：停顿填充词(那个/就是说/嗯/呃)归本维；自我贬低词(可能我不对/随便说说)归 relaxation，本维不收；
道歉词(不好意思)若后接退让归 relaxation，本维不收；单次连接用"然后"归 logicality，连续堆叠的"然后"才计入本维填充。
按填充词密度(每百字填充词数，<3 不扣)、句法完整率、冗余率、用词准确度综合打分。
锚定：0-39 填充密集/半截句/词不达意，听者难抓观点；40-69 能表达但有明显冗余或填充；
70-89 清晰流畅，偶有1-2处填充不影响理解；90-100 精准简洁无冗余一听即明。
仅输出整数。
```

### 3.2 logicality（逻辑思辨力）

**定义**：发言是否有条理、观点是否有支撑，符合读书沙龙深度交流需求。**只评"想得/组织得清不清楚"，不评流畅度**（归 clarity）。指标含原图两项（关联词、观点-论据匹配）+ 拓展两项（论证结构完整度、观点自洽性）。

**可测指标**（语义结构判断为主，规则计数仅辅助且须防刷分）：

| 指标 | 判据 | 方向 |
|---|---|---|
| 关联词**有效**使用 | 首先/其次/因此/然而/一方面…另一方面/然后(单次连接) 是否真正组织了有条理的结构 | 服务于结构=加分；堆砌无条理=不加分 |
| 观点-论据匹配 | 每个主张后是否有支撑（举例/引用书中内容/因果解释） | 无支撑主张越多越差 |
| 论证结构完整度 | 是否形成"主张→依据→(结论)"链条 | 越完整越好 |
| 观点自洽性 | 前后观点是否冲突且未说明转变 | 未解释矛盾越多越差 |

> **防刷分**：关联词不按密度计高分。"首先…其次…最后…"套壳但观点空、因果牵强 = 伪逻辑，落及格档。指标1 交模型判断"关联词是否服务于清晰论证"，prompt 显式禁止"见关联词即加分"。
> **§2#5 显式接收**：单次连接两个有先后/因果分句的"然后"作为逻辑连接词，纳入本维关联词有效使用判断；连续堆叠的"然后"不归本维（归 clarity 填充）。

**四档锚定**（示例刻意与 clarity 对照）：

| 档位 | 区间 | 含义 | 沙龙场景示例 |
|---|---|---|---|
| 差 | 0–39 | 观点跳跃、无论据、或前后自相矛盾 | "主角就是…反正我不喜欢他，但他也挺可怜的，嗯，书里写的吧。" |
| 及格 | 40–69 | 有观点、有关联词壳，但论据空/因果牵强 | "我觉得主角挺矛盾的，他一方面逃避，但最后又面对了，所以这本书还行。" |
| 良好 | 70–89 | 观点清晰且有支撑，论证链基本完整 | "我认为主角的逃避是自我保护，依据是第三章他面对父亲时的退缩反应，说明其逃避有心理根源，而非单纯懦弱。" |
| 优秀 | 90–100 | 论证严密、多层支撑、结构清晰 | "主角的逃避应理解为创伤性自我保护，而非道德缺陷。其一，第三章面对父亲的退缩显示条件反射式回避；其二，结尾他仍选择离开，说明作者未将其浪漫化为'成长'。两点共同支撑'保护机制'这一解读。" |

**边界**：
1. 与 clarity：单句内口误/半截句归 clarity；跨句结构散或观点级前后矛盾归本维。**对照样本（clarity 高+logicality 低）**："主角的逃避是一种自我保护，这个设计很打动我，作者文笔真好。"——clarity 满分，但 logicality 低（主张无论据 + 后半跳无关观点）。AI 不得因句子流畅给 logicality 高分。
2. 与 empathy：转折词（但是/不过/然而）看连接内容——承接他人观点/情绪部分归 empathy，推进自己论证部分归本维。
3. 与 interactivity（§2#6）：修辞性反问（不期待回答、强化论点）归本维；征询性反问归 interactivity；难判默认归本维。

**标尺与置信度**：以语义结构判断为主，不依赖模态相关绝对计数，real/sim 天然一致；prompt 仍禁模态词。

**prompt 片段**：
```
【logicality 逻辑思辨力 0-100】
只评"是否有条理、观点是否有支撑"，不评流畅度（流畅归 clarity）。
指标：关联词有效使用、观点-论据匹配、论证结构完整度、观点自洽性。
关联词含单次连接用"然后"；连续堆叠的"然后"归 clarity，本维不收。
防刷分：关联词不按密度加分；"首先/其次/最后"套壳但论据空、因果牵强=伪逻辑，落及格档，不得因有关联词即给高分。
边界：单句内口误/半截句归 clarity，跨句结构散或观点级前后矛盾归本维；
转折词(但是/不过)看连接内容——承接他人观点部分归 empathy，推进自己论证部分归本维；
修辞性反问(不期待回答、强化论点)归本维，征询性反问(期待对方表态)归 interactivity，难判默认归本维。
锚定：0-39 观点跳跃/无论据/自相矛盾；40-69 有观点有关联词壳但论据空或因果牵强；
70-89 观点清晰有支撑、论证链基本完整；90-100 论证严密多层支撑结构清晰。
仅输出整数。
```

### 3.3 empathy_listening（共情与倾听）

**定义**：能否**听见**对方（接收并基于对方信息回应，非自说自话）+ 能否**接住**对方（识别并回应其情绪与立场，给予接纳性反馈）。**只评"对对方的接收与回应"，不评自己说得对不对（归 logicality）、不评推不推动对话（归 interactivity）**。
> 本维显式拆"倾听/共情"两子组，避免"倾听"被"共情"吞掉。

**可测指标**（与 C 文档 §5 annotation 钩子对齐）：

| 子组 | 指标 | 数据钩子 / 判据 | 方向 |
|---|---|---|---|
| 倾听 | 延展率 | user 发言中"基于对方上一句延展"的占比 → `annotation.responds_to_seq` 指向对方句 | 越高越好 |
| 倾听 | 自说自话率 | user 发言与对方上一句话题/情绪无关的占比 | 越高越差 |
| 倾听 | 共情性追问率 | 指向对方内在体验的提问占比 | 适度为正向 |
| 共情 | 情绪命名/回应 | 是否显式回应对方的情绪（"听起来你挺失望的"） | 越多越好 |
| 共情 | 视角接纳/肯定 | 承认对方视角合理性、复述或延伸对方观点 | 越多越好 |

> **防刷分**：空洞附和（"对对对""嗯嗯""是的"无内容）**本维与 interactivity 均不计正向分**（统一决断，见 §5）——它没有真正理解，只是社交润滑。只有带内容的肯定（复述/延伸对方观点、命名对方情绪）才算本维正向。

**四档锚定**（示例刻意与 interactivity 对照）：

| 档位 | 区间 | 含义 | 沙龙场景示例 |
|---|---|---|---|
| 差 | 0–39 | 自说自话、无视对方观点与情绪，或全程空洞附和 | "嗯对。——我觉得吧，这本书其实作者写得不行……" |
| 及格 | 40–69 | 有回应但停在表面，偶有肯定却未真正接住情绪/观点 | "你说的也有道理。我比较喜欢的是另一段……" |
| 良好 | 70–89 | 能基于对方发言延展，并显式回应其情绪或视角 | "我懂你说的这种无力感，第三章那段我也看得心里一沉——他那种想逃又逃不掉的状态，确实像你说的，是自我保护。" |
| 优秀 | 90–100 | 精准命名对方情绪/复述其观点并深化，让对方感到"被听见" | "你刚才说'逃避是创伤下的自我保护'，这个解读把我之前没想通的地方点透了——你是从哪一段读出'创伤'而非'懦弱'的？我想顺着你的视角再听听。" |

**边界**：
1. 与 interactivity（提问）：共情性追问（指向对方内在体验）归本维；话题推动/征询表态/破冰提问归 interactivity；难判默认归 interactivity。
2. 与 interactivity（附和）：空洞附和两维均不计正向（见防刷分）。
3. 与 relaxation（§2#3）：道歉词本身只可能是 relaxation 信号，不作本维正向；本维看其后的理解/接纳语义。
4. 与 logicality（转折词）：转折词"但是/不过"前承接他人观点/情绪部分归本维，其后推进自己论证部分归 logicality（与 §3.2 边界2 对称闭环）。

**标尺与置信度**：倾听"延展率"可借 `responds_to_seq` 半规则计数，"情绪命名/视角接纳"靠语义；real/sim 同锚定，prompt 禁模态词。

**prompt 片段**：
```
【empathy_listening 共情与倾听 0-100】
评"是否听见并接住对方"，分倾听(基于对方上一句延展、不自说自话)+共情(命名情绪、接纳视角)两组；
不评自己说得对不对(归 logicality)、不评推不推动对话(归 interactivity)。
防刷分：空洞附和(对对对/嗯嗯/是的 无内容)本维与 interactivity 均不计正向；只有带内容的肯定(复述/延伸对方观点、命名对方情绪)才算正向。
边界：①共情性追问(指向对方内在体验)归本维，话题推动/征询表态的提问归 interactivity，难判默认归 interactivity；
②道歉词(不好意思/抱歉)本身只可能是 relaxation 信号，不作本维正向，本维看其后的理解/接纳语义；
③转折词(但是/不过)前的承接他人观点/情绪部分归本维，其后推进自己论证部分归 logicality。
锚定：0-39 自说自话/无视对方/全程空洞附和；40-69 有回应但停表面、未接住情绪或观点；
70-89 能基于对方发言延展并显式回应其情绪或视角；90-100 精准命名情绪/复述观点并深化、让对方感到被听见。
仅输出整数。
```

### 3.4 interactivity（互动积极性）

**定义**：是否**主动推动**对话向前、**维持**流转、**邀请**对方参与、**化解**冷场，使交流双向而非单向独白。**只评"有没有做推动/维持/邀请动作"，不评紧不紧张（归 relaxation）、不评接住对方内在（归 empathy）、不评自己说得对不对（归 logicality）**。

**可测指标**（语义判断为主，问号/占比只作弱辅助）：

| 子项 | 判据 | 数据/计算 | 方向 |
|---|---|---|---|
| 主动发起 | 主动开启新话题/新角度（非顺对方延展——顺延展归 empathy 倾听） | 语义 | 越多越好 |
| 推动性提问 | 征询表态/推进话题/破冰/邀请发言类提问 | 语义为主，问号弱辅助 | 适度为正向 |
| 邀请/让渡 | 主动 cue 对方、把话头交出、沙龙里 cue 沉默者 | 语义 | 越多越好 |
| 冷场处理 | 沉默/卡壳后 user 主动破冰或转话题 | 语义+时序 | 有则加分 |
| 发言占比失衡 | user 发言占比极端（1v1 中 >80% 且全程无邀请） | 1v1 可算；沙龙无归属缺数据 | **仅极端扣分（刹车项）** |

> **刹车项**：占比失衡只是"极端独白"的刹车，正常范围不影响、绝不靠"占比低"加分。沙龙无说话人归属时按"语义看有无邀请"兜底。

**四档锚定**（示例纯 interactivity 动作，不掺共情语义）：

| 档位 | 区间 | 含义 | 沙龙场景示例 |
|---|---|---|---|
| 差 | 0–39 | 全程被动，只附和或沉默，从不发起/提问/邀请 | "嗯。对。……（沉默）" |
| 及格 | 40–69 | 有接话但被动，偶应一句却不推进、不抛问题、不让渡 | "我觉得也是。那段挺有意思的。" |
| 良好 | 70–89 | 主动提问或抛新角度，维持流转 | "你刚才提到第三章，我倒想问问——你觉得作者为什么在那儿突然转折？" |
| 优秀 | 90–100 | 主动推进 + 邀请对方 + 平衡发言 + 化解冷场 | "这个'自我保护'的角度很新，我顺着追一句：那结尾的离开你怎么看？——对了，刚才一直没说话的那位，你对这段是不是也有感觉？" |

**边界**：
1. 与 empathy（提问）：共情性追问归 empathy；推动/征询/破冰/邀请提问归本维；难判默认归本维（与 §3.3 边界1 同向闭环）。
2. 与 empathy（回应）：功能性接话/轮替/邀请归本维；内容上接住对方内在归 empathy；一句兼有按子句拆。
3. 与 logicality（§2#6）：征询性反问归本维；修辞性反问归 logicality。
4. 与 relaxation：本维评"做没做动作"，relaxation 评"做时紧不紧张"。紧张但努力提问→本维不扣、relaxation 扣；松弛但回避不说话→本维低、relaxation 高。两维独立。

**防刷分**：① 问号不直接计高分，共情性追问归 empathy、修辞反问归 logicality，须语义过滤后剩下的推动/征询/邀请类提问才计；② 空洞附和 = 中性噪声，本维与 empathy 均不计正向，其"无主动互动"缺陷由"主动发起/邀请子项=0"自然体现。

**标尺与置信度**：提问率若纯靠问号标点，会在 real 语音场景偏置（语音转录标点常不准），故提问意图**以语义为主、标点弱辅助**；real/sim 同锚定，prompt 禁模态词。

**prompt 片段**：
```
【interactivity 互动积极性 0-100】
评"是否主动推动/维持/邀请/化解冷场，使交流双向"，子项：主动发起新话题、推动性提问、邀请让渡(含cue沉默者)、冷场处理；发言占比仅极端独白(1v1>80%且无邀请)作刹车扣分，不靠占比加分。
不评紧不紧张(归 relaxation)、不评接住对方内在(归 empathy)、不评自己说得对不对(归 logicality)。
防刷分：①问号不直接计高分，共情性追问归 empathy、修辞反问归 logicality，须语义过滤后剩下的推动/征询/邀请类提问才计；
②空洞附和(嗯嗯/对对对/是的 无内容)=中性，本维与 empathy 均不计正向，其缺陷由"主动发起缺失"自然体现。
边界：①共情性追问归 empathy，话题推动/征询/破冰/邀请的提问归本维，难判默认归本维；
②功能性接话/轮替/邀请归本维，内容上接住对方内在归 empathy，一句兼有按子句拆；
③征询性反问(期待对方表态)归本维，修辞性反问归 logicality；
④紧张但努力提问→本维不扣(归 relaxation 扣)，松弛但回避不说话→本维低(归 relaxation 高)，两维独立。
锚定：0-39 全程被动只附和或沉默、从不发起/提问/邀请；40-69 有接话但被动、不推进不抛问题不让渡；
70-89 主动提问或抛新角度、维持流转；90-100 主动推进+邀请对方+平衡发言+化解冷场。
仅输出整数。
```

### 3.5 relaxation（情绪松弛度）——本项目特色核心维度

**设计基调（先读，统摄本维）**：
1. **文本只是松弛度的代理指标**。真正的紧张/从容信号在副语言（语速/停顿/音量/声音颤抖），文本看不见。故本维文本分定位为"基于文本可观察信号的近似推断"，可信度天然低于其他维。
2. **本维在差异觉察中采信自评**（见 §4），因紧张是纯内在体验——AI 测不到，用户自己知道。

**定义**：用户交流时的从容/自信程度，是否被紧张驱使而退缩、防御或掩饰。**只评"紧不紧张/敢不敢"，不评说没说清楚（归 clarity）、不评接没接住对方（归 empathy）、不评做没做互动动作（归 interactivity）**。

**可测指标**：

| 指标 | 计算口径 | 数据/判断 | 方向 |
|---|---|---|---|
| 退缩/自我贬低词密度 | 每百字：可能我不对/随便说说/我说不好/我也不确定/我瞎说的（§2#2） | 规则计数，阈值初值 **<2/百字不扣**（比填充词严，常量待校准） | 越高越差 |
| 道歉退让词密度 | 每百字：不好意思/抱歉/打扰一下，**且后接退让/收回观点**（§2#3） | 规则+看后接 | 越高越差 |
| 防御性语言 | 被质疑/分歧时的退缩式澄清：你别误会/我不是那个意思/我说错了/当我没说 | 语义 | 有则扣分 |
| 自我表露意愿 | 是否敢表达真实个人感受/立场/脆弱面，而非只说安全中立话 | 语义，**正向必要条件** | 越高越好 |

**四档锚定**：

| 档位 | 区间 | 含义 | 沙龙场景示例 |
|---|---|---|---|
| 差 | 0–39 | 退缩/道歉密集，频繁自我否定、收回观点，几乎不表露真实想法 | "嗯…我可能说得不对啊，随便说说的，不好意思，我其实也没想好，算了不说了。" |
| 及格 | 40–69 | 偶有退缩，观点带较多 hedging，自我表露浅 | "我觉得…可能主角是有点逃避吧，我也不太确定，随便聊聊。" |
| 良好 | 70–89 | 较少退缩词，能表达立场，偶有礼貌道歉但不影响观点输出 | "我倾向于认为主角在逃避，这个我比较有把握——当然我也好奇大家怎么看。" |
| 优秀 | 90–100 | 从容、立场清晰、不靠道歉铺垫，敢表露真实感受与脆弱面，被质疑不防御 | "这段我读的时候其实挺难受的，因为我在主角身上看到了自己——所以我坚持认为那是逃避，不是懦弱。" |

**边界**：
1. 与 clarity（§2#1）：停顿填充词归 clarity，本维不收。
2. 与 clarity（§2#2）：自我贬低/退缩词归本维。
3. 与 empathy（§2#3 + 防御vs接纳）：道歉词本身只可能是本维信号，不作 empathy 正向；被质疑时防御性退缩归本维负向，开放性接纳归 empathy 正向。
4. 与 interactivity（对称 §3.4 边界4）：紧张但努力提问→本维扣、interactivity 不扣；松弛但回避→本维高、interactivity 低。两维独立。
5. 与 empathy（自我表露vs共情）：说出自己的真实感受/脆弱 = 本维正向；回应他人感受 = empathy；兼有按子句拆。

**防刷分**：纯沉默/纯附和不得本维高分——"没退缩词"可能只是"没说话"。本维高分须满足**自我表露意愿**正向必要条件：既不退缩、又有实质立场/表露输出才给高分；整段无实质输出则保守给中低分。（与 interactivity、empathy 对空洞附和/沉默的中性处理三维统一。）

**标尺与置信度**：real/sim 同锚定，退缩词阈值两源共用，prompt 禁模态词。**置信度落地**：prompt 须要求模型"仅就文本可观察的退缩/防御/表露信号打分，不臆测语音层面的紧张或从容"。

**prompt 片段**：
```
【relaxation 情绪松弛度 0-100】
评"交流时是否从容自信、有无被紧张驱使的退缩/防御/掩饰"，指标：退缩/自我贬低词密度、道歉退让词密度(看后接是否退让)、防御性语言、自我表露意愿。
不评说没说清楚(归 clarity)、不评接没接住对方(归 empathy)、不评做没做互动动作(归 interactivity)。
特征归属：停顿填充词(那个/就是说/嗯/呃)归 clarity，本维不收；自我贬低词(可能我不对/随便说说)归本维；
道歉词(不好意思/抱歉)本身只可能是本维信号、不作 empathy 正向，看其后是否退让；被质疑时防御性退缩归本维、开放性接纳归 empathy。
防刷分：纯沉默/纯附和(无实质立场输出)不得高分——"没退缩词"可能只是"没说话"，须结合自我表露意愿判断，无实质输出则保守给中低分。
置信度约束：仅就文本可观察的退缩/防御/表露信号打分，禁止臆测语音层面的紧张或从容(语速/停顿/音量等文本不可见)。
锚定：0-39 退缩/道歉密集、频繁自我否定收回观点、几乎不表露；40-69 偶有退缩、观点多hedging、表露浅；
70-89 较少退缩、能表达立场、有一定表露；90-100 从容立场清晰、不靠道歉铺垫、敢表露脆弱、被质疑不防御。
仅输出整数。
```

## 4. 差异觉察机制与 relaxation 例外

**机制**：每次评估同时存 AI 五维分（C 文档 evaluation_record / conversations.Evaluation）与用户每维相对自评 `self_relative`（up/flat/down）。详情页查最近几条，现算 `divergence_flags`（不存表）：当某维 AI 分较上次上升、但用户该维选了 down（或反之显著背离）时，触发中性提示，引导回看复盘。

**两种解读，按维度区分**（核心，勿混）：

| 维度 | 背离解读 | 提示措辞方向 |
|---|---|---|
| clarity / logicality / empathy_listening / interactivity | **认知偏差觉察**：客观表现与主观感受不符，可能用户低估自己（社交焦虑常见负面自我评估偏差） | 中性邀请回看，如"AI 的观察和你的感受不太一样，要不要一起回看这段？" |
| relaxation | **采信自评**：紧张是内在体验，文本测不到，AI 分高+自评紧张 ≠ 用户低估，而是 AI 测不到 | 采信感受，如"这一维你的感受比文本更能说明问题，我们记下了。" |

> ⚠️ relaxation 维**禁用**"你低估自己/你其实做得不错"类措辞——对真实焦虑用户这是二次否定（gaslighting）。具体文案归前端/产品，见挂记⑧。
> 措辞总则：所有维的差异提示均须中性、邀请式，不得居高临下判定用户"错了"。

## 6. 挂记清单

### 6.1 rubric 自身挂记
- ① **语义维方差**：logicality / interactivity / relaxation 的语义子项评分方差天然高于规则维，封测重点看一致性，必要时补 few-shot 对照样本。
- ③ **empathy 沙龙钩子缺失**：`responds_to_seq` 在沙龙无说话人归属时填不了（speaker_ref=unknown），与亲密度沙龙降级同源；1v1/sim 不受影响，沙龙 empathy 倾听子项第一版按"语义兜底、不强制计数"。
- ④ **annotation 词表标准化**：`intent`/`emotion`/`keywords` 现文档为自由文本，本 rubric 仅语义借用；词表标准化属 AI 模块 annotation 规范，不在本 rubric 范围，须立规范防口径漂移。
- ⑤ **interactivity 沙龙占比缺数据**：发言占比失衡子项依赖对方发言量，沙龙无归属时缺数据，按"语义看有无邀请"兜底。
- ⑥ **语音提问识别率**：提问意图改"语义为主、标点弱辅助"后，封测须专项验证语音场景的提问识别率。
- ⑦ **relaxation 语音升级**：若接入语音特征（语速/停顿/音量，联动 C 文档 §8#4 语音管道），relaxation 应升级为"文本+语音"双信号，文本分降为辅助。
- ⑧ **relaxation 差异觉察文案**：§4 的"采信自评"措辞须落到前端差异提示文案，relaxation 维禁用"你低估自己"类措辞。

### 6.2 引用 C 文档挂起项（不重复定义，见 C 文档 §8）
- self_state 状态标签词表；category 关系分类词表；隐私部署口径；沟通辅助输入形态（连带沙龙多人录入与亲密度沙龙分支）。

### 6.3 阈值/边界初值（封测校准，非精确值）
- 填充词密度阈值 <3/百字；退缩词密度阈值 <2/百字；环阈值（内≥70/二40–69/外<40，见 C 文档）；四档边界。均为常量，封测用真实评分分布校准。

## 7. 封测校准清单

1. 五维两两相关系数：若相邻维（如 clarity-logicality、empathy-interactivity）相关系数过高（>0.7），回查 §2 仲裁表是否被 prompt 落实。
2. 各维评分方差：语义维（logicality/interactivity/relaxation）方差是否显著高于规则维，是则补 few-shot。
3. real vs sim 同维度均值差：若某维 real 系统性偏低，查是否残留模态相关计数（clarity 填充词、interactivity 标点），按各维消偏差手段修正。
4. 差异觉察触发率与 relaxation 措辞：核对 relaxation 维未出现"低估自己"类文案；前四维认知偏差提示是否中性。
5. overall 口径：确认第一版等权 = ROUND(AVG 五维)，与 C 文档及 user_profile 一致；改加权前须迁移历史或接受折线断层。
